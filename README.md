## Development

Code shared with the app, like the topo format, lives in the
[Common](https://github.com/Escalar-Alcoia-i-Comtat/Common) repository, included as a git submodule in `common`. Clone
with `git clone --recurse-submodules`, or fetch it in an existing clone with:

```shell
git submodule update --init
```
